# x-admin 视觉方向预览 · v2

先打开 `index.html`（已在 Review 面板打开），再点进任意一套。每套内部顶部可切换 **登录 / 看板 / 用户管理**。

> 这一版不是同一套壳换配色：三套的布局结构、字体、信息密度和操作方式都不同。
> 品牌名、Logo、主色仍是占位（x-admin / 字标 X），选定方向后替换。

## 01 · Ledger 账簿

**结构**：顶部报头 + 无侧栏 + 印刷式账页
**关键词**：衬线标题、细分隔线、行号、墨绿、印章红

- 用“账簿”隐喻组织后台：数字是账目，操作是记录，日志是页脚
- 统计区不是卡片，是一列被横线切开的数字
- 表格带行号，筛选是下划线输入而不是盒子
- 登录页是一张对开的封面，没有卡片
- **适合**：希望后台有机构感、编辑感，而不是“又一个管理模板”的团队

## 02 · Workbench Liquid Glass（已选定）

**结构**：图标轨 + 上下文栏 + 右侧检查器（保留 Workbench 布局）
**关键词**：液态玻璃、极光光场、悬浮面板、橙色高光、跟随鼠标的折射感

- 导航是悬浮的深色玻璃胶囊，内容区是半透明白玻璃
- 背景是缓慢漂移的蓝/紫/桃/薄荷极光色场，玻璃面板会透出颜色
- 每块玻璃会跟随鼠标产生高光（`--mx / --my`），图表线有柔光
- 登录页是两块悬浮玻璃 + 旋转的光环，不靠阴影堆叠
- 用户列表右侧仍是常驻检查器，角色改成玻璃胶囊选择
- **适合**：每天在数据里来回操作、希望工具有质感但不呆板的团队

> 这是当前选定的方向。如果觉得玻璃太透/太亮/动效太多，可以逐项调。

## 03 · Night Shift 夜班

**结构**：顶部导航 + 大字号 hero + 1px 网格面板
**关键词**：暖黑、琥珀、鼠尾草绿、宋体大标题、长行距

- 不是霓虹科技风，是“深夜新闻编辑室”：暖黑、低对比、长时间看不刺眼
- 看板先用一句话告诉你系统状态，再给数字
- 用户列表底部有常驻批量操作条，选中后直接处理
- 登录页只有一句话和一个表单，用大面积留白和暖光
- **适合**：运维、监控、需要值夜班或长时间盯屏的团队

## 下一步

选定一套（或说明想混合的部分）后：

1. 把该方向翻译成 antd 6 `ConfigProvider` theme token（颜色、圆角、密度、字体）
2. 产出最终 `SPEC.md`：页面清单、路由、API、数据表、权限码、里程碑
3. 确认后开始搭建项目
